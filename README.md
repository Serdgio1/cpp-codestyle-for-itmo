# Code Style Fixer

Автоматическое расширение для VS Code, которое:
- Переносит длинные `if` (>30 символов)
- Приводит имена функций в UpperCamelCase
- Оборачивает `if (...) continue;` в блок
- Обрезает строки длиннее 120 символов
- Форматирует отступы в C/C++ коде

## Горячие клавиши

- `Ctrl+Alt+Shift+L` — Исправить кодстайл текущего файла

## Установка

1. Скачайте `.vsix` файл из репозитория
2. В VS Code: Extensions → Install from VSIX
3. Перезапустите VS Code

## Использование

Откройте любой C/C++ файл и нажмите горячие клавиши или вызовите команду через `Ctrl+Shift+P → Fix Code Style`.
